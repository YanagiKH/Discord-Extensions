# Discord Extensions

Discord Extensions は、コントロールパネルを通じてローカルの Discord 関連拡張機能を管理するための、スタンドアロンのデスクトッププラグインホストです。

これは私の実験的なプロジェクトであり、公式にサポートされているプラグインではないため、すべてのリスクはご自身で負っていただく必要があります――とはいえ、その可能性は極めて低いですが :)

## 採用しているアーキテクチャ

- Electron + TypeScript UIシェル
- 共有マニフェストおよびIPC契約レイヤー
- 組み込みのボリュームリミッタープラグインテンプレート
- `.zip`、フォルダ、および `plugin.json` 用のローカルプラグインインポート機能
- プラグインの状態および設定の永続的な保存
- トレイからの起動およびシングルインスタンス動作
- 将来のネイティブヘルパー向け Java ブリッジモジュール

## 現在のリポジトリが提供する機能

- プラグインの有効化／無効化トグル
- 歯車アイコン風の詳細パネルによるプラグインごとの設定
- インポートされたプラグインのマニフェストスキャン
- ローカルのプラグインワークスペースへのアーカイブの解凍
- インストール済みプラグインおよび状態へのワークスペースフォルダへのアクセス

## 主なスクリプト

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run typecheck`

## 境界

このリポジトリは独立したコンパニオンホストとして実装されており、Discordクライアントのインストールディレクトリを変更したり、Discordアプリケーションにコードを注入したりすることはありません。
